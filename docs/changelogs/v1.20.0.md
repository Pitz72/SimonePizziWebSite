# v1.20.0 — Editor Migliorato & Dashboard Analytics Estesa (11 Giugno 2026)

## Editor di testi (RichTextEditor / Tiptap v3)

### Bug corretti
- **Stati attivi non sincronizzati**: con Tiptap v3 i bottoni della toolbar, il
  select degli heading e "Rimuovi Link" non si aggiornavano spostando il cursore
  senza digitare (`shouldRerenderOnTransaction: true` ripristina il comportamento v2).
- **Conteggi a zero su contenuto esistente**: parole/caratteri ora si inizializzano
  in `onCreate` (prima restavano a 0 finché non si digitava).
- **Bozze "fantasma"**: in Tiptap v3 `setContent` emette `onUpdate` di default —
  aprire un articolo esistente marcava il form dirty e creava bozze spurie in
  localStorage. Fix: `setContent(value, { emitUpdate: false })`.

### Miglioramenti
- Validazione URL nei link (allowlist http/https, percorsi `/`, `#`, `mailto:` —
  blocca `javascript:` e `data:`); input tipo `www.esempio.it` completato
  automaticamente con `https://`.
- Validazione/normalizzazione URL YouTube (youtube.com / youtu.be /
  youtube-nocookie o ID video 11 caratteri) con errore inline nel popover.
- Nuovi bottoni **Undo/Redo** con stato disabled reale.
- Tooltip con scorciatoie tastiera su tutti i bottoni (Ctrl+B, Ctrl+I, ...).
- **Tempo di lettura stimato** nel footer (~200 parole/min).
- Accessibilità: `role="toolbar"`, `aria-label`, `aria-pressed`, focus ring;
  `ToolbarBtn` tipizzato (era `any`).

## Dashboard Analytics (admin)

Nuove statistiche (analytics.php GET globale, chiavi additive retrocompatibili —
`weekly_views` e le chiavi storiche restano invariate):

- Serie giornaliera views con **selettore periodo 7/30/90 giorni**
- Views **oggi / ieri**, ultimi 7 giorni **vs 7 precedenti** (delta % colorato)
- **Visitatori unici** (DISTINCT ip_hash) sul periodo
- **CTR dei CTA** (click/views %), media views per articolo pubblicato
- Contenuti: articoli pubblicati/bozze, progetti visibili
- Newsletter: confermati, pending, nuovi iscritti 30 gg
- Messaggi: totali e **non letti**
- **Top categorie per visualizzazioni** (barre proporzionali)

UI: riga di 10 mini-card sopra i grafici, stile coerente (zinc/green); grafico
"Andamento Visualizzazioni" con selettore periodo e fallback legacy.

## Verifica funzionale area admin

Review statica completa post-modifiche: tutti i 36 metodi di api.ts combaciano
con gli endpoint PHP (metodo HTTP + Auth::check dove serve), rotte /admin tutte
coperte dal loader di auth, recovery bozze e salvataggio intatti, password min 12
client+server coerente, nessun URL assoluto anomalo (check Origin soddisfatto).
Typecheck e `php -l` puliti. Esito: nessun bloccante.
