Release focalizzata sulla risoluzione del blocco degli embed video di YouTube dovuto alle restrizioni della Content Security Policy (CSP) su Apache/DreamHost, e sulla preparazione editoriale per l'arrivo dell'IDE Favella Studio.

---

## 1. Risoluzione Blocco Video YouTube (Fix CSP)

### La causa
Sui browser moderni, tutti i video YouTube incorporati negli articoli del sito mostravano un riquadro grigio con icona di divieto (`🚫`). 
L'audit degli header HTTP ha rivelato che il web server Apache a monte della docroot inviava una policy CSP legacy priva della direttiva `frame-src`. In assenza di tale direttiva, il browser applicava come fallback `default-src 'self'`, bloccando tassativamente il caricamento di qualsiasi iframe esterno (`youtube.com` o `youtube-nocookie.com`).

### L'intervento
In `public/.htaccess` sono state introdotte le direttive per azzerare la policy ereditata e forzare una CSP aggiornata e permissiva per gli embed video:
```apache
Header always unset Content-Security-Policy
Header unset Content-Security-Policy
Header always set Content-Security-Policy "default-src 'self'; script-src 'self' 'unsafe-inline'; style-src 'self' 'unsafe-inline' https://fonts.googleapis.com; font-src 'self' data: https://fonts.gstatic.com; img-src 'self' data: https: blob:; connect-src 'self'; object-src 'none'; frame-src https://www.youtube-nocookie.com https://www.youtube.com; frame-ancestors 'self'; base-uri 'self'"
```
- Eseguito il deploy del nuovo file `.htaccess` in produzione con backup preventivo automatico in `~/backup-sito/`.
- Verificato via `curl` che l'header HTTP inviato live contenga correttamente `frame-src https://www.youtube-nocookie.com https://www.youtube.com;`.
- I video YouTube sono tornati pienamente visibili e riproducibili in tutte le pagine pubbliche e nelle bozze.
