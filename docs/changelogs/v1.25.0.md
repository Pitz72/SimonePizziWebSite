# v1.25.0 — Correttezza dei contenuti (07 Luglio 2026)

Release tematico sulla **coerenza tra ciò che l'admin salva e ciò che il pubblico
vede**. Nasce da una verifica dal vivo: un progetto nascosto sembrava ancora visibile
e una sottocategoria rinominata mostrava il vecchio nome. Entrambi i sintomi erano
artefatti (sessione admin + cache browser), ma hanno fatto emergere problemi reali di
propagazione e un bug SEO lato server.

## Novità

- **Cache-Control: no-store sugli endpoint pubblici dinamici** (`navigation.php`,
  `projects.php`, `categories.php`, `articles.php`): prima non inviavano alcun header di
  cache, così il browser serviva risposte vecchie e le modifiche admin (rinomina
  categoria, hide/show progetto, modifica articolo) non si vedevano fino alla scadenza
  cache o a un hard refresh. Ora si propagano subito. `index.php` già inviava no-store.
- **Badge "Nascosto" per l'admin** (`src/pages/AllProjects.tsx`): in `/tutti-i-progetti`
  — l'unico punto pubblico dove un progetto non visibile appare all'admin loggato — le
  card con `is_visible=0` mostrano una pillola ambra + bordo ambra. Indicatore puramente
  lato pannello: il server non invia mai i nascosti ai visitatori anonimi.

## Fix

- **[SEO] Colonna inesistente `cover_url` in `index.php`**: le query dei progetti
  (homepage e pagina "Tutti i Progetti" per i crawler) selezionavano `cover_url`, colonna
  che non esiste (la tabella usa `cover_image`). In MySQL questo lanciava un'eccezione a
  ogni visita di un crawler, catturata dal `catch` silenzioso: la homepage perdeva tutto
  il blocco **JSON-LD** (`WebSite` + `Person`) e la sezione progetti. La colonna non era
  nemmeno usata nell'output → rimossa dalla SELECT. Ripristinati structured data e
  sezione progetti per Google.
- **Fallback categorie allineato** (`src/hooks/useCategories.ts`): `DEFAULT_CATEGORIES`
  conteneva i nomi vecchi hardcoded (`Progetti Software`, `Narrativa e Pubblicazioni`,
  ...), mostrati per un istante a ogni caricamento e in modo permanente se l'API di
  navigazione falliva. Allineati ai nomi pubblici correnti + aggiunta categoria `Web`.
- **`catch` in `adminDashboardLoader`** (`src/loaders.ts`): se `stats`/`analytics`
  fallivano, la dashboard crashava (il componente accede a `rawStats.*` senza guardie).
  Ora degrada in modo morbido mostrando zeri.

## Note

- Dopo il deploy serve **un** hard refresh per svuotare l'eventuale risposta già in cache;
  da lì in poi le modifiche sono immediate.
- I 4 file PHP sono standalone e si caricano via FTP senza rebuild; il badge e i fix React
  richiedono invece la `dist/` ricostruita.
