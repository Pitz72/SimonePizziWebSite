# v1.23.0 — Fix soft-404 SEO + redirect vecchie categorie (20 Giugno 2026)

Google Search Console segnalava **13 pagine "Non trovata (404)"** e **0 pagine
indicizzate**. Indagando: `index.php` (SEO Engine v2.0) restituiva **HTTP 200 per
qualsiasi URL**, anche inesistente — il fallback SPA mandava ogni rotta sconosciuta
al motore che rispondeva 200 con meta generici. Risultato: **soft-404** che Google
classifica come "Non trovata" e che impediscono una corretta indicizzazione.

## Fix

- **`index.php` — vero HTTP 404 per pagine inesistenti**:
  - Articolo non presente nel DB (`pageType=article` con slug sconosciuto) → 404
  - Categoria non presente nel DB (`pageType=category` con slug sconosciuto) → 404
  - Rotte con 3+ segmenti non riconosciute (es. `/sw/rlm/Per`, `/pages/software/...`,
    `/chi-sono/articoli/...`) che prima cadevano sul default homepage → 404
  - Ogni 404 invia `http_response_code(404)` + `<meta name="robots" content="noindex, follow">`
    sia sul percorso crawler sia su quello umano, più un body "Pagina non trovata".

- **`.htaccess` — redirect 301 vecchie categorie** (struttura pre-categorie, gen 2026,
  ancora nell'indice Google). Match SOLO esatto, i sotto-path danno 404 reale:
  - `^/software/?$` → `/progetti-software`
  - `^/libri/?$` → `/narrativa-e-pubblicazioni`

## Verifiche post-deploy (tutte verdi)

- `/sw/rlm/Per`, `/software/gestore-duplicati-musicali`, `/chi-sono/articoli/...`,
  `/categoria-inesistente` → **404** (prima 200)
- `/software` → 301 → `/progetti-software`; `/libri` → 301 → `/narrativa-e-pubblicazioni`
- Home, articolo reale, categorie reali → **200** invariati

## Noto / da fare (separato)

Le ~28 directory prerenderizzate fisiche sul server (una per categoria) scavalcano
`index.php` e servono ai crawler un guscio SPA vuoto con titolo generico, invece
dell'HTML dinamico. Residuo della vecchia prerenderizzazione (deprecata dalla v1.12.0
ma mai rimossa dal server). Probabile causa principale dello "0 indicizzate".
Cleanup da valutare: rimuovere quelle directory così le categorie passano da `index.php`.
