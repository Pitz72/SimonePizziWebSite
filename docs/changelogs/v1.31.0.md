# v1.31.0 — La barra dei caricamenti (22 ottobre 2026)

Prima delle funzioni perse con la migrazione dal React a tornare nel pannello. L'elenco
completo sta nel §2 della [revisione del 16 ottobre](../AUDIT-2026-10-16.md); il 22
ottobre il confronto file per file con il vecchio `src/` ha trovato le voci che mancavano
ancora (barra, PDF, suggerimenti dei tag, CSV degli iscritti, filtri, colore e
allineamento nell'editor). Si rifanno una alla volta, ognuna con la sua versione.

## Caricare le immagini — `8748455`
- Una zona dove si trascinano o si scelgono **più immagini insieme**, nella finestra
  «Scegli un'immagine» della scheda articolo e, di nuovo, nella pagina **Libreria**.
- Una riga per file con la **barra di avanzamento**, i KB o MB spediti e l'esito. Finito
  l'invio, la barra resta in movimento senza numero mentre il server converte in WebP.
- I file partono uno dopo l'altro. Formato e peso si controllano prima di spedire.
- Un file lasciato cadere fuori dalla zona non apre più l'immagine al posto della
  pagina; chiudere la scheda a metà coda chiede conferma.
- Nella Libreria, a fine coda senza errori la pagina si rilegge e le nuove sono le prime.
- La percentuale la calcola il browser (`XMLHttpRequest`), come nel React: la funzione di
  PHP `session.upload_progress` resta spenta.

## Il pannello sul telefono — `444879b`
