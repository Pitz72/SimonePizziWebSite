# v1.21.0 — Sezione Messaggi nel Pannello Admin (12 Giugno 2026)

I messaggi del form Contatti erano salvati nel database e notificati via email,
ma il pannello admin non aveva alcuna pagina per consultarli: il backend
(`messages.php`) era pronto da tempo, orfano di frontend. La card "Messaggi non
letti" introdotta in v1.20.0 contava quindi messaggi che non si potevano leggere
né marcare. Questa release chiude il cerchio.

## Novità

- **Nuova pagina `/admin/messages`** (voce "Messaggi" in sidebar, icona
  MessageSquare, dopo Newsletter):
  - lista ordinata per data con mittente (nome + email), oggetto, anteprima,
    data italiana; non letti evidenziati (sfondo verde tenue, badge "Non letto")
  - click → espansione inline col testo completo; l'apertura di un non letto
    lo **marca automaticamente come letto** (contatore aggiornato live)
  - bottone **Rispondi** (mailto: con "Re: <oggetto>") e **Elimina** con conferma
  - contatore non letti/totali in testata; stati loading/empty/errore gestiti
- **messages.php**: il GET admin supporta ora `?id=N` per il messaggio completo
  (la lista restituisce solo una preview di 200 caratteri) — Auth::check(),
  prepared statement, 404 se inesistente.
- **api.ts**: nuovi metodi `getMessages`, `getMessage`, `markMessageRead`,
  `deleteMessage`.
- **Dashboard**: la mini-card "Messaggi Non Letti" è ora cliccabile e porta
  alla nuova pagina.
