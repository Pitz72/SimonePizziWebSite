# v1.18.1 — Fix link PayPal donazioni

**Data:** 22 Maggio 2026
**Tipo:** Hotfix

## Problema

Tutti i link "Sostieni con PayPal" presenti sul sito puntavano all'account sbagliato (`paypalme/simonepizzi`), che non corrisponde all'account reale associato alle donazioni del progetto. Conseguenza: le donazioni effettuate dagli utenti finivano potenzialmente in un account errato o inesistente.

## Fix

Sostituito l'URL PayPal in tutti i punti del frontend:

- `https://www.paypal.com/paypalme/simonepizzi` → `https://www.paypal.com/paypalme/runtimeradio`

### File modificati

- `src/pages/ContactPage.tsx` (riga 221) — bottone "Sostieni con PayPal" nella pagina contatti
- `src/components/CommunityHub.tsx` (riga 53) — CTA donazione nel modulo community
- `src/components/SingleArticle.tsx` (riga 188) — bottone donazione in fondo agli articoli

## Note operative

- Il fix riguarda **solo il codice React**. Se in qualche articolo del DB è stato linkato manualmente `paypalme/simonepizzi` nel campo `content` HTML, va corretto via admin (l'app non lo intercetta).
- Stessa vulnerabilità potrebbe esistere su altri siti correlati (es. `/relitto`) che sono in repository separate — da verificare separatamente.

## Deploy

Build + FTP della nuova `dist/` su DreamHost.
